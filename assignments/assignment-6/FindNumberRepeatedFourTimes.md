# Find Number Repeated Four Times

## Problem

Given an array of size `n`, all the numbers in the array are repeated **3 times**, except for one number which is repeated **4 times**.

Find the number that is repeated 4 times.

### Constraints

- `0 < n < 10^5`
- `0 < nums[i] < n`
- Expected Time Complexity: `O(n)`
- Expected Space Complexity: `O(1)`

### Example

**Input:**

```text
[1, 2, 3, 4, 1, 2, 4, 1, 2, 3, 4, 3, 3]
